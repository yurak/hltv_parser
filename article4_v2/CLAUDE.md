# Стаття 4 (подання в Дніпро) — інструкції проєкту

Відтворюваний конвеєр написання наукової статті. **Це четверта стаття** серійної публікаційної лінії
«Ідентифікація шаблонів поведінки користувачів онлайн-сервісів».
**Тема:** ідентифікація поведінкових шаблонів користувачів фінансових онлайн-сервісів (антифрод)
на основі інженерії ознак та аналізу розділюваності у просторі ознак.
**Цільовий журнал:** №47 «Information Technology: Computer Science, Software Engineering and Cyber
Security» (НТУ «Дніпровська політехніка») — див. `paper/journal_requirements.md`.
**Дедлайн:** відсутній — роллінгове приймання через OJS, 4 випуски/рік (рецензування швидке).

## Залізні правила (non-negotiable)

- Ніколи не вигадувати статистичні результати: p-values, розміри ефектів, обсяги вибірок, дати, відсотки.
- Кожне числове твердження в Results має мати provenance: `outputs/tables/`, `outputs/figures/` або `outputs/logs/`.
- Якщо значення немає — писати «not available» і позначати як невирішене.
- Не редагувати файли в `data/raw/`. Похідні файли — лише в `data/processed/`.
- Не вигадувати DOI, ORCID, Scopus ID — звіряти через Crossref / grafiati.com; невідоме позначати TODO.
- Використовувати plan mode перед великим аналізом, реструктуризацією рукопису, роботою з вимогами журналу.
- Тримати `review/revision_log.md` актуальним для кожної суттєвої зміни.
- Розділяти результати й інтерпретацію; уникати необґрунтованих причинних тверджень.

## Специфіка журналу №47 (відмінності від №85 Луцьк — критичні)

- **Внутрішні посилання — APA** `(Автор, рік)`, НЕ числові `[1]`.
- **Два списки:** «Література» (ДСТУ 8302:2015, ≥10 джерел з DOI) + «References» у стилі **APA**.
- **Обсяг 10–20 с.**; TNR **14**, інтервал **1,5**, поля **2 см** з усіх боків.
- **Анотація ≥1800 знаків** кожною мовою; **ключові слова 3–7**.
- Доп. метадані: **ORCID + Scopus ID + блок «To cite»**.
- Лапки «ялинки»; переноси вимкнено; сторінки не нумерувати; формули MS Equation.

## Структура проєкту

- `data/raw/` — оригінальний датасет `df.csv` (Predict Chargeback Frauds, Kaggle), не редагувати.
- `data/processed/` — очищені/похідні датасети.
- `scripts/` — `analyze.py` (усі експерименти), `fraud_baseline.py`, `export_docx.py`.
- `outputs/tables/` (T1–T9), `outputs/figures/` (F1, F2), `outputs/logs/` — згенеровані артефакти.
- `paper/` — `manuscript.md`, `journal_requirements.md`, `submission_checklist.md`, `outline.md`.
- `references/` — настанови журналу (`journal_guidelines/`), джерела, бібліографія.
- `review/` — коментарі рецензента, revision log, summary для наукового керівника.

## Відтворюваність

- Усі числа в `paper/manuscript.md` походять з `outputs/`, згенерованих `scripts/analyze.py`.
- Перезапуск: `python scripts/analyze.py` (читає `data/raw/df.csv`, пише в `outputs/`).
- Мова: основний текст українською; обов'язкові англомовні метадані (назва, анотація, ключові слова).
