# Submission Checklist — журнал №47 (Дніпровська політехніка)

Звірка перед поданням. Джерело вимог: `paper/journal_requirements.md`.

## Формат файлу
- [ ] MS Word `.doc`/`.docx`
- [ ] Сторінки НЕ нумеровані
- [ ] Поля: 2 см з усіх боків
- [ ] TNR 14, інтервал 1,5; абзац 1,25 см
- [ ] Лапки «ялинки»; переноси вимкнено
- [ ] Формули — MS Equation
- [ ] Обсяг 10–20 сторінок
- [ ] Завантажено й застосовано офіційний Word-шаблон з journals.politehnica.dp.ua

## Структура (IMRAD)
- [ ] УДК
- [ ] ORCID усіх авторів (TODO: вписати реальні)
- [ ] Scopus Author ID (TODO: вписати або вилучити, якщо немає)
- [ ] Блок «To cite» (бібліоопис статті)
- [ ] Назва — укр + англ
- [ ] Анотація ≥1800 знаків кожна — укр + англ
- [ ] Ключові слова 3–7 — укр + англ (зараз 7 ✓)
- [ ] Вступ → Матеріали і методи → Результати → Обговорення → Висновки
- [ ] Література (ДСТУ 8302:2015, ≥10 джерел, з DOI)
- [ ] References (APA)

## Бібліографія та посилання
- [ ] Внутрішні посилання — APA `(Автор, рік)` ✓ (числові `[1]` НЕ використовувати)
- [ ] «Література» — ДСТУ 8302:2015, ≥10 джерел; DOI у кожному, де можливо
- [ ] Усі DOI звірено через grafiati.com / Crossref
- [ ] «References» — APA, транслітерація укр. джерел

## Якість і доброчесність
- [ ] Перевірка на плагіат пройдена
- [ ] Кожне число в Results має provenance (`outputs/`)
- [ ] Немає необґрунтованих причинних тверджень

## Подання
- [ ] Реєстрація автора в OJS journals.politehnica.dp.ua/index.php/it
- [ ] Подання через OJS
- [ ] Дедлайн: ВІДСУТНІЙ (роллінгове приймання, 4 вип./рік; рецензування швидке ~5/20 днів)
