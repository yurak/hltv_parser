# Куди класти демки

Сюди — розпаковані `.dem` файли з HLTV (GOTV). Вони не потрапляють у git.

## Критерії відбору

- мапа **de_mirage** (інші мапи скрипт відсіє автоматично);
- **64 тік** (демки з іншим тікрейтом відсіюються — порівнювати їх не можна);
- CS2, бажано один період патчів (2024–2025), бо механіка руху змінювалась;
- різні суперники й турніри для одного гравця — інакше «підпис» буде підписом
  конкретного матчу, а не гравця.

## Скільки і яких

Мінімальний план — **10 демок**:

- 5 mirage-матчів з ropz;
- 5 mirage-матчів з s1mple.

Кожна демка дає всіх 10 гравців, тому їхні тіммейти автоматично стають
референсною групою з тим самим покриттям (по 5 матчів кожен). Разом виходить
~10–12 гравців по ~55 раундів на сторону — цього достатньо і для надійності
профілю 0.9, і для міжматчевої валідації (навчання на 4 матчах, перевірка на 5-му).

Якщо ropz і s1mple зустрічались на mirage в одному матчі — така демка цінніша
за дві окремі: обидві цілі в однакових умовах (той самий сервер, той самий мета-контекст).

## Назва файлу

Ім'я файлу стає `match_id`, тому давай осмислені назви:
`2025-03-14_faze-vs-navi_mirage.dem`

